1. Server Requirements

Use cPanel MultiPHP Manager or Select PHP Version and enable the required PHP extensions.

  • PHP 7.3 or newer
  • bcmath
  • ctype
  • curl
  • fileinfo
  • json
  • mbstring
  • openssl
  • pdo
  • pdo_mysql
  • tokenizer
  • xml
  • zip

Recommended permissions are usually 755 for folders and 644 for files. Some hosts require 775 for storage and bootstrap/cache.

2. Upload Files to cPanel

  1. Upload the project files to your domain root or subfolder.
  2. Upload vendor if Composer is not available on the server.
  3. Delete any local-development .env before a fresh install.
  4. Delete stale cache files if present.
  5. Visit the installer URL.
bootstrap/cache/config.php
bootstrap/cache/routes.php
bootstrap/cache/events.php
https://your-domain.com/install

The installer checks PHP, extensions, permissions, license, database connection, imports the bundled SQL file, and then asks you to create the first Super Admin account as the final step.

4. License Verification

BankCore supports license verification during install and from the admin panel.

INSTALL_LICENSE_ENDPOINT=https://your-license-portal.com/api/verify-license

If no endpoint is set, the license is stored locally. For production sales, use the separate license portal and point the banking app to its API.

Admin location: Admin Panel -> Settings -> License Manager

5. License Portal Setup

The separate license portal project lives in:

C:\Build\repo\bankcore-license-portal
  1. Upload the portal to a separate domain or subdomain.
  2. Configure the portal .env.
  3. Use MySQL for production if possible.
  4. Run migrations if SSH is available.
  5. Login and create licenses.
APP_NAME="BankCore License Portal"
APP_URL=https://licenses.yourcompany.com
LICENSE_PORTAL_PASSWORD=ChangeThisPassword
DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=your_license_db
DB_USERNAME=your_license_user
DB_PASSWORD=your_password
php artisan migrate --force

7. Admin Login

After installation, open the admin login page and create or update admin users from the admin panel.

https://your-domain.com/admin/login

8. SMTP Setup

Open Admin Panel -> Settings -> App Settings -> Email Settings.

Mail Server: smtp
SMTP Host: mail.your-domain.com
SMTP Port: 465 or 587
SMTP Encryption: ssl for 465, tls for 587
SMTP Username: your mailbox email
SMTP Password: mailbox password
From Email: your mailbox email
From Name: your bank name
For cPanel email, create the mailbox first under Email Accounts, then copy the manual mail client settings.
  • Confirm DNS MX records are correct.
  • Confirm SMTP password is correct.
  • Try port 587 with tls.
  • Ask the host if outbound SMTP is blocked.
  • Clear app cache from admin after saving settings.

9. Payment Setup

Payment settings are managed from Admin Panel -> Settings -> Payment Settings.

  • Add deposit and withdrawal methods.
  • Add manual bank transfer details.
  • Configure gateway API keys where supported.
  • Confirm gateway webhook/callback URLs match your live domain.
  • Keep test keys separate from live keys.
GatewaySetup notes
PaystackCreate account, copy public and secret keys, add keys under Payment Settings, test a small deposit.
FlutterwaveCopy public key, secret key, and secret hash. Confirm callback URL points to the live domain.
StripeCopy publishable and secret keys. Use live keys only after testing.

10. Frontend CMS Setup

The landing page is CMS-ready. Open Admin Panel -> Settings -> Front Page.

  • Website Contents controls landing text, button labels, and URLs.
  • Images controls landing images.
  • FAQ(s) controls FAQ content.
  • Testimonials controls testimonials where used.

For landing content, add a Website Content entry where Title of Content is the CMS key and Content Description is the text or URL value.

home.hero.eyebrow
home.hero.title.line1
home.hero.description
home.hero.primary_button
home.hero.primary_url
home.features.heading
home.feature.1.title
home.feature.1.description
home.cta.heading

For landing images, upload an image and set Title of Image to one of these keys:

home.visual.phone.image
home.security.image.large
home.security.image.small
home.app.image
home.testimonial.1.image
home.testimonial.2.image
home.testimonial.3.image
If a CMS key is missing, the landing page uses the built-in default text or image.

12. Common cPanel Issues

Please provide a valid cache path

storage/framework/views
storage/framework/cache/data
storage/framework/sessions
bootstrap/cache

Create these folders if missing, then make them writable.

App still tries to connect to database before install

.env
storage/installed
bootstrap/cache/config.php
bootstrap/cache/routes.php
bootstrap/cache/events.php

Delete those files, then revisit /install.

500 error after moving to server

  • Confirm .env exists after install.
  • Confirm APP_KEY is set.
  • Confirm PHP extensions are enabled.
  • Confirm storage and bootstrap/cache are writable.
  • Confirm database credentials are correct.
  • Confirm APP_URL matches the live domain.

Email verification or KYC settings

enable_verification
enable_kyc
enable_kyc_registration
